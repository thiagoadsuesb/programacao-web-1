# Programação Web I - De Artigo para HTML

## Sobre o Projeto

Este projeto foi desenvolvido como atividade da disciplina **Programação Web I** do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Estadual do Sudoeste da Bahia (UESB)**.

A proposta da atividade consistiu em transformar um artigo científico em uma página HTML, reproduzindo sua estrutura e organização utilizando exclusivamente as tags estudadas nas aulas e nos materiais da Unidade I.

---

## Artigo Utilizado

**Assistente Virtual Inteligente para Instituições Educacionais: Aplicação da Técnica RAG no IFBot**

Autores:

* Wesley Folly Volotão de Souza
* Ianne Lima Nogueira
* Anderson Veiga de Souza

---

## Objetivos da Atividade

* Aplicar conceitos fundamentais de HTML;
* Utilizar corretamente títulos e subtítulos;
* Estruturar conteúdos através de parágrafos;
* Implementar listas ordenadas e não ordenadas;
* Criar navegação interna utilizando âncoras;
* Reproduzir a organização visual de um artigo científico;
* Utilizar o GitHub para versionamento e publicação do projeto.
